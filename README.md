# Crypto Signal Monitor v7.2.0

Lighter-Monitor für BTC + 23 Altcoins. Prüft Kurs/Volumen, Orderbuch, Funding, 05/20/60-Minuten-Druck, kurzfristige Speed-/Activity-Auffälligkeit, Extremity, BTC-Kontext, 7/14/30-Tage-Regime sowie verifizierte Makro-/Coin-Ereignisse.

**Anzeige**
- Oben: drei auffälligste Altcoins plus BTC; akute Ereignisse und `SHK!` können Vorrang erhalten.
- Unten: `05/20/60`, `J`, `E`, Extremity und relevante Warn-/Ereigniscodes.
- `🟡 ▷   ` = neutral/seitwärts.

**Kürzel**
- `J00–J99`: historische Springer-Neigung; `J??` = noch keine belastbare Historie.
- `E00–E99`: Risiko aus verifizierten Ereignissen; `E??` = unzureichende Kernquellen-Abdeckung.
- `P00–P99`: BTC-Nähe zu einem relevanten Rundlevel; `P??` = nicht belastbar bestimmbar.
- `U…`: verifizierter Token-Unlock. `SHK!`: ungewöhnlich starker einseitiger 15-Minuten-Kursausreißer. `SEC!` / `NET!`: akutes verifiziertes Security-/Netzwerkereignis.
- `K!` / `L!` / `F!` / `V!` / `B!` / `R!` / `RS!` / `CH!`: Kosten / Liquidität / Funding / Tape / BTC-Kontext / Regime / relative Wende-Schwäche / Chase-Warnung.
- `DATA!` / `CND!` / `BOOK!` / `GAP!` / `STALE!`: Daten-/Kerzen-/Orderbuchfehler, Kerzenlücke oder veraltete Daten.
